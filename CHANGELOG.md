# Changelog

## v1.2.0 — 2026-10-08

- First public release on GitHub.
- Update notice: GitHub installs check for a newer release once a day and show a banner and notification.
- Fixed extension ID (manifest key), so updating by replacing the folder keeps your price history.
- Release automation: GitHub Releases and Chrome Web Store publishing from a version tag.

## v1.1.0 — 2026-10-08

- Older prices from archive.org (Wayback Machine) snapshots, shown as orange points.
- Keepa's 1-year Amazon chart on demand.
- Croma comparison via Croma's search API; repaired Croma JSON-LD.
- Fixes from testing on the live sites: Amazon's split brand/model titles, stricter variant matching (e.g. iPhone 16e vs 15).
- Unknown periods in the chart are drawn dashed.

## v1.0.0 — 2026-10-08

- Price history chart, lowest/average/highest and buy verdict on product pages.
- Comparison across Amazon.in, Flipkart, Croma, Reliance Digital, Tata CLiQ, Myntra and AJIO.
- Tracking with target-price alerts and background checks.
